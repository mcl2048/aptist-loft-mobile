# VPN 全局网络隐私层 · 0.1.2 实施决定

状态：实施中。此记录补充本机两份 v3.6 设计文档和用户新增的官方移动端要求，尚不代表新版本已经通过验收。

DNS/WebRTC 防泄漏放在共享 TUN、DNS 和业务流路径。Rust 管理策略、策略代际、冻结 UID 作用域与实际生效状态；Go 执行有界检测和代理准入。当前 SOCKS5、HyrakenX、Hyraken Pro 与后续 QUBF/Hyraken 适配器复用同一层。默认全隧道覆盖进入 VPN 的全部流量；可选按 APP 模式准确显示冻结的有效 UID 范围。

现有 Hyraken X/Pro OPEN 已支持域名目标。专用 `ExchangeDNS` 属于 WireX/HyrakenBusiness 的接口，不能当作普通 X/Pro 已有能力。六组公网 TCP/UDP53 探测失败只证明这条转发路径没有有效答案，不能证明节点内部 DNS 有问题。

首个官方客户端模式为明确标识的 `node_domain_fake_ip`：有界合成地址用于路由，业务 OPEN 恢复原域名，由所选节点处理连接目标。合成回答与真实解析器回答分别记录。验收必须从 VPN Network 发起查询，再用返回的合成地址完成原域名的证书校验和 HTTPS 200，并核对没有物理业务 DNS 查询。`wire_tcp` 保留为显式配置、独立验证的解析器转发方式；其失败证据不随新模式改写。

| 资源与行为 | 初始约束 |
| --- | --- |
| DNS 映射 | 最多 256 条、256 KiB 计入已有 8 MiB 新增缓冲账本 |
| 地址隔离元数据 | 固定65,534槽的期限表/cursor/单调起点，预留528 KiB计入8 MiB总量；动态预算扣除该预留，只有分配时被动回收 |
| 合成 TTL | 60 秒；活动引用与已宣告期限内不重分配，取消/代际变化失败关闭 |
| 输入/回答 | 查询最多 4 KiB；真实模式回答有界至 65,535 字节 |
| 查询/业务准入 | 共用既有 64 项上限及 8 秒操作期限，不增加后台轮询 |
| RR 能力 | 合成模式支持 IN A；IPv6 禁用的 AAAA 明示空回答，其他 RR/DNSSEC 请求明确拒绝或使用独立获准的真实模式 |
| 代理证明 | 绑定实际 Ready 客户端、策略代际和 TUN 作用域；丢失、Stop、Abort 和替换立即撤销 |
| 检测状态 | 复用 Gateway 有界 DNS/STUN/TURN/DTLS 规则，固定 TCP 前缀状态，禁止保存查询/载荷日志 |

静态复核发现早期候选在每次TTL到期查询时消耗新地址，最终可能永久耗尽。修正规则为稳定域名先续期同一映射，旧映射/活跃借用释放后保留最后广告TTL的隔离期限，到期按新分配被动回收；超限是可恢复的拒绝，没有定期重启或直连回退。Stop清理动态域名/流/资源，保留无域名/载荷的固定期限元数据，单独报告`dns_allocator_bytes`。IP包不携带策略代际，不能永久辨识任意超TTL缓存；可证明保证限定在有效TTL/活跃引用和当前映射/代理证明上，新旧证明不复用。

WebRTC 策略沿用源码的 `proxy_only` / `block`。前者要求已确认代理出口，后者阻止已识别的 RTC；未知加密流量仍受 VPN 作用域约束。包过滤不能保证隐藏浏览器自行枚举的 SDP 本地地址，因此回执只报告实际网络防护范围和检查依据。

Hydra 的纯整形代码和 X/Pro 钩子已经在上游存在，但旧移动适配尚未安装这些配置。Rust 冻结独立 Hydra 配置，默认 Disabled；显式移动配置通过现有钩子安装。整形计数、整形轮换、连接代际、DNS/WebRTC 防护与连接就绪分别报告。Hydra 不承担 DNS、WebRTC 或重连职责。

QUBF Next/v3 属于独立传输，需要匹配 wire v2/v3 节点、受保护物理拨号以及移动端窗口/缓冲预算。现有单族 24+24+16 MiB 保留上限不能直接成为 APP 默认；后续接入使用共享隐私层及现有所有权/取消契约。

验证包括任意端口 DNS/STUN、完整/畸形 UDP、分段 TCP、普通业务与空 UDP 保持、回复再检查、旧代际、映射耗尽与 TTL/活动引用、Ready 丢失/Stop 竞态、拒绝前无违规字节、实际 DNS→域名 HTTPS 和 Android UID/TUN 范围。实机 Fold、PSS、Doze、电池和 72 小时验收仍单独留证。
