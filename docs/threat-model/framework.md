Scope: LOFT0.1.2-LYNX framework under final integration, source-pinned Gateway adapters, Rust domain/UniFFI, private Android control/VPN process and native Compose. Executed checks belong to their recorded source/artifact identities. This foundation record does not certify the later BFF, Shield, policy service or mobile penetration-test roadmap.

Protocol authentication, Portal identity and device/software evidence are distinct authority sources. Ordinary SOCKS5 provides no tunnel encryption. A local held-TUN block is not remote credential revocation, a normalized server is not trusted, and a finite buffer ledger is not a measured PSS or battery budget.

Failure policy preserves confirmed routing and actual resource ownership. A failed or unknown receipt cannot publish Connected/Disconnected, software-safe, mailbox-empty or remote-revoked results. The forwarding adapter responds to immutable Unavailable projections even when Rust's mutable owner is poisoned.

Production sign-off still needs the exact final artifacts, independent mobile security review, real device/system and power tests, encrypted recovery and any enabled cloud/security adapters. The validation report lists executed and unexecuted checks separately.
