## Native pages

The overview shows local account state, Rust-confirmed VPN state, the selected node, and app upload/download totals for the current or last joined session. The shortcut grid uses the native module catalog and exposes Mail when verified Hub capabilities allow it. The VPN rail opens the paged directory directly. The directory shows the selected node and the active node independently. Its upper-right menu opens import, routing, connection details and diagnostics, and refreshes the directory. The circular shield stays below the scrolling content on both pages and dispatches Connect, Cancel or priority Stop according to the current state. The persistent rail and stable routes also apply in the adaptive panes. ## VPN data path

- The IPv4 UDP destination check compares address and port values already held by the flow. A Go 1.27.4 host microbenchmark measured a median of 238.5 ns/op before and 6.49 ns/op afterward, with three allocations and 40 bytes reduced to zero. This measurement covers the destination check.
- HyrakenX allocates a 1 KiB app downlink buffer. The change saves 63 KiB per X association and keeps the full uplink buffer for consuming over-limit local packets. The real packet test admitted 64 bounded X associations, rejected the 65th and confirmed complete lease release after Stop. X accepts app UDP payloads from 1 through 1,024 bytes. Pro accepts 0 through 65,507 bytes. The app-payload accountant measured a 17.84 ns/op median for a synthetic write with zero allocations. It recorded one 324.7 ns/op outlier while other host work ran.
- VPN idle paths retain event-driven Android control and the existing Go scheduler limit. The review considered QUIC keepalive, HTTP/2 PING and Go heap limits. Carrier NAT behavior, radio wakeups, battery use, PSS, real link throughput and 72-hour operation require physical measurements.
