# Actual VPN extension contract

This is the coordinated extension after the controller APK baseline. It is not a claim of physical-device VPN acceptance. Android never reads or embeds guide/TEST.TXT credentials; root/Go live tests keep those inputs private.

The private AIDL controller stays non-exported in `:vpn`. A separate OS `VpnService` is exported only with `BIND_VPN_SERVICE` and the `android.net.VpnService` action. Both use one shared Rust core owner. Go initialization is explicit for VPN/diagnostic operations, independent of Rust readiness; guest/account/mail startup does not initialize Go or a TUN. A running or intentionally blocked VPN owns a foreground lease and the core after UI unbind. Ordinary idle/controller release closes native resources.

User `prepare()` permission is bound to the selected node and observed Rust generation. The private controller calls `beginVpn`; the opaque ticket owns canonical validated materials, a distinct attempt epoch and frozen routing. `takeRawNode()` is single-use and used only inside `:vpn`. No private URI goes into Binder snapshots, notifications, intent extras, logs or preferences. Go runs outside the Rust state lock.

Android establishes the real TUN with IPv4 prefix `198.18.0.1/30`, MTU `1280`, route `0.0.0.0/0` and synthetic DNS `198.18.0.2`. Go proxies synthetic DNS over tunnel TCP to the explicit public resolver `1.1.1.1:53`; this is not claimed as Gateway enterprise DNS. There is no direct DNS fallback. IPv6 is blocked in owned VPN scope by the Builder default-blocked family: no IPv6 address/route/allowFamily; Go additionally drops IPv6. Unselected UID groups remain direct. Final device gates must verify actual IPv6/DNS/app exits.

Enabled routing resolves current installed package/UID groups, expands linked members before freezing, and rejects incomplete/empty/oversized groups. Every Builder `addAllowedApplication` must succeed; an empty effective list is never interpreted as all apps. Rust ready receipts require exact equality with frozen effective packages. UI describes UID-sharing scope and cannot claim an unselected member of a routed UID remains direct.

The socket protector captures a real physical `Network` with `NET_CAPABILITY_NOT_VPN` and `INTERNET`, never an active VPN network. It duplicates the raw socket handle, validates socket ownership with public fstat/S_ISSOCK and an Internet socket address, binds the duplicate to that Network, protects the actual socket before connect/send, then closes its duplicate. The Go caller retains the original descriptor. Node-name resolution uses API29 `DnsResolver` on the same Network with a fixed 5-second deadline, bounded callback executor, `CancellationSignal`, and at most 8 literal IPv4 answers/1024 bytes. Stop cancels signals and releases wait latches; no `getAllByName` fallback or unbounded DNS worker is introduced.

Go duplicates and owns the supplied TUN descriptor; Android keeps the original `ParcelFileDescriptor`. Actual Start/ready requires authenticated protected transport and a real running TUN adapter, then a trusted Rust receipt. A version/capability flag cannot report Connected. The bounded Go state listener returns promptly and posts to the owner actor; actual transport loss clears Connected through Rust even with UI hidden.

On authentication/runtime/network failure after TUN establishment, Android retains the original TUN and foreground owner until explicit user Stop/onRevoke. Closing only Go's duplicate is not actual Stop. A trusted Rust blocked/held-scope receipt must expose this condition rather than a Kotlin-inferred status. Stop/revoke first cancels Go/DNS outside the normal 8-entry import queue; Rust priority cancellation invalidates stale readiness. Disconnected is published only after original TUN closure and native-resource-release receipts agree. No timer or retry declares a recovered connection.

Official references reviewed: https://developer.android.com/develop/connectivity/vpn and https://developer.android.com/develop/background-work/services/fgs/service-types . Configured VPN apps are an eligible system-exempted foreground-service integration; user grant and actual service startup remain required. Permission/type behavior, Always-on, lockdown, profile scopes, process death and foreground delivery require final API29/35/36 handset validation.


Transport envelope version2 carries its own publication sequence beside the schema1 Rust snapshot. Every actor/priority/subscription/receipt capture reserves sequence, queries nonblocking Rust and encodes under one common short lock. Consumers reject old/equal publication values within a fresh binding epoch, so cached Stop/poison projections may safely share a Rust generation. Exhaustion fails transport explicitly. No Go/network operation occurs under that capture lock.

Go JSON receipt admission requires always-emitted Boolean ownership_pending and complete strict resource fields. A pending constructor, shutdown join or notification worker cannot be interpreted as released from zero counters. The actual Android original-PFD facts are combined with Go/native and platform callback joins before a stopped receipt. The instrumentation source uses a bounded one-use private file under targetContext.filesDir; no raw URI belongs in instrumentation arguments/APKs/logs. Compiled tests are not executed device evidence.

Forwarding-disabled admission also requires ownership_pending=false and the Android Start worker joined. One-shot FailureDispatch admission prevents Abort's BLOCKED notification from repeating Abort/Rust failure mutations and generating an unbounded snapshot/page-query loop. Later callbacks may finish a no-TUN attempt or publish one confirmed Blocked transition. Original-TUN and foreground ownership remain until explicit Stop/revoke. The Go factory validates inert capability JSON, including the actual Android gomaxprocs=2, before runtime construction.

The node-page AIDL operation is read-only, bounded and separate from snapshot publication: queryNodePage(requestId, offset, expectedGeneration, observer), with offsets0/50/100/150 and at most50 redacted rows. Visible-only requests reject stale binding/request/generation callbacks and preserve a stable selected ID plus one bounded metadata record across page changes. It does not initialize Go or reconcile business Stop.

The positive literal TLS instrumentation requires an example.com HTTPS hostname handshake and an HTTP200 status line bounded to128bytes/five seconds. Physical IPv4 bootstrap occurs before the VPN; no tunneled-DNS evidence is inferred. The DNS case explicitly queries the VPN Network with NO_CACHE_LOOKUP/NO_CACHE_STORE and remains a separate deployment-policy gate. Run guest and every private-node case in a fresh process/test context.

Final Stop ingress establishes its queue guard and captured attempt atomically, applies only the priority Rust fence, cancels terminal resolution and closes the captured original before resource monitor lookup, snapshot publication or Go waits. Coalesced delayed callbacks are scoped against the active attempt and cannot close replacements. CurrentCore/retainUi/publication and Go Abort run on the existing reserved worker; Abort precedes StartOwnership.await. A failed enqueue yields ENGINE_STOP_INCOMPLETE without a false stopped/resource-release receipt. Actual forwarding disable remains unconfirmed while cleanup is queued until strict Go facts arrive.

NodeResolutionOwnership closes QueryGate terminally on cancelPending rather than using reusable cancelAll. A query that passed a stale stopped precheck is rejected after cancellation; an admitted signal cannot complete or rearm afterward. Public Android CancellationSignal checks are compiled in AndroidQueryCancellationTest and create no DNS/network/TUN. Their Android execution remains a separate gate.

The input file is unlinked immediately after opening and material is wiped after import.
